# EXERCICE Projet personnel

## Objectif

- Mettre en oeuvre les principes POO

## Donnée

Vous imaginez un scénario de votre choix, afin de créer un petit programme java qui mettra en action 5-10 classes.

Vous procéderez en 3 étapes:
- 1. Description du scénario en texte
  - Quel est le thème et les différents éléments gérés par mon application
  - Quelles sont les fonctions utilisateur de mon application
- 2. Création du diagramme de classe avec Entreprise Architect.
  - Vous mettez en oeuvre (au minimum) les principes d'encapsulation, d'héritage, et différent type de couplage (inclu une utilisation d'interface).


## Réalisation et durée
Vous réalisez vos diagrammes de classe avec EA.

Vous faites valider votre description textuelle par l'enseignant.

Optionnel : 
- Vous réalisez un diagramme UseCase pour compléter votre description textuelle.
- Vous implémentez votre diagramme de classe en Java.


Durée: 120'
