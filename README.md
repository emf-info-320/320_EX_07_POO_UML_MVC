## Introduction

Dans le D400 et ce cours vous avez déjà étudié et appliqué quelques principes de la POO (Programmation Orientée Objets).

Ce thème POO est repris ici plus en détails pour vous faire découvrir quelques-uns de ses principes fondamentaux. Face à un problème à résoudre, ces connaissances vous aideront à identifier et à proposer les classes, les interfaces, les interactions, ... les plus adéquates.

## Objectifs

- Comprendre les principes fondamentaux de la POO
- Comprendre l'application des ces principes dans le cas du Pattern MVC
- Être capable de créer un diagramme de classe avec Entreprise Architect et Mermaid
- Comprendre la liaison dynamique
- Comprendre l'injection de dépendance
- Concevoir un diagramme de classe qui respecte les enseignements reçus pour résoudre un problème donné
